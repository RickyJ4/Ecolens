# EcoLens · Environmental Intelligence

EcoLens is a community-first environmental intelligence project built in Vancouver. It is a personal project, not an organization. It puts live multi-hazard data on a map that people can question in plain language, and pairs it with documented local stories about the places those hazards touch.

Live site: https://ecolenswebapp.web.app

## What it does

- **Map.** A MapLibre GL map with live hazard layers: NASA FIRMS fire detections ranked by measured radiative power rather than hectares, NOAA flood gauges, US Drought Monitor classes, USGS earthquakes, and GDACS alerts with their published impact figures and affected-area geometry. An ask bar at the bottom of the map answers questions from the data actually loaded, hands what it cannot settle to the Atlas engine when one is reachable, and files the resulting finding in Environmental News.
- **Environmental News.** A news desk over the GDACS alert wire, mirrored server-side every 15 minutes. Each alert is enriched from the published event record (impact reports listed one by one, affected countries, duration, published affected area, Copernicus mapping products, press coverage) and written up as a story with a source line under every paragraph and a "View on map" button that opens the affected geometry.
- **Community.** Documented places and stories with consent-based sourcing.
- **Atlas Agent.** An optional local agentic GIS companion that the map can hand analysis to. EcoLens runs fully without it.

## Principles that gate every change

These are enforced in review, not aspirational.

1. **No fabricated data.** Nothing derived from a ratio, a lookup table or a model is shown as a measurement. If a number cannot be sourced, the section is removed, not caveated.
2. **Never sum impact reports.** GDACS impact reports nest and supersede one another. Adding them invents people.
3. **Never invent a buffer.** Only geometry the source published is drawn.
4. **Never compute evacuation routes.** Official orders and counts are surfaced as published.
5. **Provenance on everything.** Each figure names its source and time window.
6. **No gamification.** No points, streaks, badges or engagement counters. Editorial framing, like a local newspaper.

## Architecture

```
Flutter web shell (MVVM, provider)             Firebase (project-specific)
  lib/views          screens                     Hosting      the built web app
  lib/viewmodels     state and network           Firestore    news_feed, community, stories
  lib/core/theme     Paper & Ink design tokens   Functions    Python, Gen 2: FIRMS proxy,
                                                              hazard monitor, daily archive,
assets/maplibre_map  the map page                             GDACS news mirror
  index.html                                     App Check    reCAPTCHA v3
  js/*.js  MapLibre GL JS 5.1 layers,
           Ask-the-map, Atlas bridge,           Public GCS bucket
           anomaly desk, spatial stats            daily hazard archive and the GDACS
                                                  mirror, as gzip GeoJSON
```

The map page is plain JavaScript (IIFE modules on `window.*`, no bundler) so its logic can be exercised with Node without a browser. The Flutter shell embeds it in an iframe and talks to it over `postMessage`.

## Data sources

| Source | Used for |
|---|---|
| NASA FIRMS (VIIRS SNPP and NOAA-20) | Active fire detections and radiative power |
| GDACS | Multi-hazard alerts, impact reports, affected-area geometry, the news wire |
| USGS | Earthquakes |
| NOAA NWPS and NWS | Flood gauges and weather alerts |
| US Drought Monitor | Drought classes, contiguous US only |
| OpenStreetMap and Nominatim | Boundaries and place resolution |
| BC Wildfire Service | Fire records for British Columbia |

## Running locally

Prerequisites: Flutter (stable channel), Python 3.11 or newer, the Firebase CLI, and Node 18 or newer for `node --check` on the map modules.

```bash
cd ecolens
flutter pub get
flutter run -d chrome
```

Firebase config for the web app is generated by `flutterfire configure` into `lib/firebase_options.dart`. Point it at your own Firebase project; the values there are public by design.

## Configuration and secrets

Nothing secret is committed. You will need:

| Where | Key | How it is supplied |
|---|---|---|
| Functions | `NASA_FIRMS_MAP_KEY`, `GEMINI_API_KEY`, `ADMIN_TRIGGER_TOKEN`, `GFW_API_KEY`, `IUCN_API_TOKEN` | `firebase functions:secrets:set NAME`; each function binds what it uses in its decorator |
| Flutter build (optional) | `GEMINI_API_KEY` for client-side analysis, `GFW_API_KEY` for the Global Forest Watch client | `flutter build web --dart-define=NAME=...` |
| Android | `android/app/google-services.json` | Download from the Firebase console; gitignored |
| 3D simulations | Google Map Tiles API key | Copy `assets/3d_simulations/keys.example.js` to `keys.js` (gitignored) and fill it in. The key ships to browsers, so restrict it to your hosting domain and to the Map Tiles API in Google Cloud Console |
| Story viewer | Cesium ion access token | Copy `assets/story_viewer/js/keys.example.js` to `keys.js` (gitignored). Scope the token to the assets the viewer needs |
| Local scripts | Firebase admin service account for `lib/backend/firebase_scout.py` | Keep it at `~/.ecolens/serviceAccountKey.json` or point `GOOGLE_APPLICATION_CREDENTIALS` at it |

Never place `serviceAccountKey.json` or any admin credential in the tree. The `.gitignore` blocks the known names, not new ones. The Firebase web API key in `lib/firebase_options.dart` and the reCAPTCHA site key are public by design; restrict them by API and referrer in the Google Cloud Console rather than hiding them.

## Deploying

```bash
cd ecolens
flutter build web --release
firebase deploy --only hosting --project YOUR_PROJECT
firebase deploy --only functions --project YOUR_PROJECT
firebase deploy --only firestore:rules --project YOUR_PROJECT
```

Hosting caches map assets for up to an hour. Bump the `?v=` stamps in `assets/maplibre_map/index.html` and the bridge banner in `js/atlas-bridge.js` whenever map JavaScript changes.
